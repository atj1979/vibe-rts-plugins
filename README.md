# Vibe RTS Plugins

Plugin packs for Something Vibe RTS. This repo will host units/buildings content that the main game can load by tag and group name.

## Structure (planned)

- src/index.js
- src/plugins/<group>/plugin.json
- src/plugins/<group>/units.js
- src/plugins/<group>/buildings.js

## Current Status

Scaffold only. We will copy the existing units and buildings from the main game into a default plugin group when we finalize the plugin loader in the main repo.
